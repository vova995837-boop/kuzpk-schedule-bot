# Расписание колледжей Кузбасса — Telegram-бот

## Что уже реализовано
- регистрация пользователя и сохранение выбранной группы;
- выбор между КузПК, КузТАГиС (Кемерово), ПГТ им. В. П. Романова (Прокопьевск) и ЯМК (Салехард); колледж и группа сохраняются отдельно для каждого пользователя;
- расписание КузТАГиС, звонки, преподаватели и кабинеты читаются из публичной папки Яндекс Диска; файлы обновляются ботом автоматически и не хранятся в репозитории;
- главное меню разделено на «Расписание» и «Курсы»; расписание включает дни, неделю, звонки, преподавателей и кабинеты;
- раздел «Курсы» показывает публичный список Moodle для выбранной учебной группы, распределяя его по типам дисциплин (МДК, СОО, СГ, ОП и другим);
- роли student / starosta / teacher / admin;
- рассылка объявления старостой своей группе;
- общая рассылка только для главного администратора;
- чтение расписания и справочников из Google Sheets;
- SQLite для пользователей и их ролей.
- локальное чтение расписания и справочников из XLSX-файла, если Google Sheets не подключены (файл расписания нужно предоставить отдельно и не публиковать в репозитории);
- расписание за 7 ноября 2026 года можно подключить из отдельных XLSX-файлов групп и преподавателей; эти файлы не входят в репозиторий.
- раздел «Образование» показывает календарный график, учебные планы и программы ГИА по специальности выбранной группы; PDF отправляются в чат со ссылкой на официальный источник КузПК.
- просмотр расписания в одном сообщении: стрелки листают дни, недельный режим перелистывает дни выбранной недели;
- меню использует только inline-кнопки под сообщениями; команда `/start` скрывает старую нижнюю клавиатуру Telegram;
- просмотр расписания по выбранному преподавателю или кабинету с листанием по дням;
- группы при выборе разделены по кодам специальностей; кабинеты сгруппированы по корпусам (1 — главный, 2 — мастерские, 3 — спортивный комплекс, 4 — общежитие);
- записи двух уроков одной пары объединяются в одну пару, включая строки XLSX, где во втором уроке имя преподавателя повторно стояло в колонке предмета;
- расписание звонков разбито по учебным дням, сменам, парам и переменам;
- добавлен отдельный просмотр спортивных секций на 2026–2027 учебный год с расписанием по дням и ответственными;
- хранение истории объявлений и подтверждение перед общей рассылкой;
- администратор назначает старост и преподавателей командой `/setrole ID student|starosta|teacher`.

## Важно
Это рабочая версия. Для КузПК укажи Google Sheets либо подключи локальный XLSX отдельно рядом с `bot.py` или через `SCHEDULE_XLSX`. Для КузТАГиС оставь публичную папку доступной по ссылке; её адрес задаётся через `KUZTAGIS_YANDEX_PUBLIC_URL`.

## Запуск локально
1. Установи Python 3.11 или новее.
2. Распакуй архив.
3. Создай Telegram-бота через @BotFather и скопируй токен.
4. Скопируй `.env.example` в `.env` и заполни `BOT_TOKEN` и `ADMIN_ID`. В `ADMIN_ID` укажи свой числовой Telegram ID.
5. Установи зависимости:
   `python3 -m venv .venv && .venv/bin/python -m pip install -r requirements.txt`
6. Запусти:
   `.venv/bin/python bot.py`

## Развёртывание на Railway
В репозитории есть `railway.json`: Railway запускает бота как постоянно работающий процесс и перезапускает его после сбоя. Для деплоя выбери этот GitHub-репозиторий и ветку `main`.

В Variables добавь `BOT_TOKEN`, `ADMIN_ID`, `TIMEZONE=Asia/Novokuznetsk` и `DATABASE_PATH=/data/college.db`. Прикрепи Volume к сервису по пути `/data`, чтобы база пользователей сохранялась между перезапусками и новыми версиями.

### ИИ-обновление расписания
Администратор может открыть «Управление» → «ИИ · обновить расписание», выбрать колледж и отправить Excel (`.xlsx`/`.xlsm`) или текстовый PDF с таблицей. Бот подготовит предпросмотр заменяемых групп и дат и изменит расписание только после подтверждения. В этом же режиме можно написать текстовую правку для одной группы и даты; бот уточнит их, если указание неоднозначно. Сохранённые изменения находятся в SQLite и применяются поверх расписаний колледжей после перезапусков.

Для текстовых правок добавь в Railway Variables `AI_API_KEY`, `AI_API_URL=https://api.openai.com/v1/responses` и `AI_MODEL=gpt-6-luna` (или совместимые endpoint и model стороннего провайдера). Ключ API создаётся у провайдера и хранится только в секретных Variables, не отправляй его сообщением и не добавляй в GitHub. Запросы к API могут тарифицироваться отдельно от Railway; загрузка обычного файла и предпросмотр работают без ИИ. Файлы передаются сервису бота для разбора, а текст правки и данные расписания для неё — выбранному AI API. ИИ не применяет изменения сам: перед записью бот показывает сводку и просит подтверждение.

Чтобы бот показывал расписание КузПК, подключи Google Sheets через `GOOGLE_SHEET_ID` и `GOOGLE_SERVICE_ACCOUNT_JSON`, либо предоставь ему Google Drive folder через `GOOGLE_DRIVE_FOLDER_ID` и `GOOGLE_SERVICE_ACCOUNT_JSON`. Для единой книги с листами «3. Расписание пар (группы)» и «1. Расписание звонков» бот берёт самую новую XLSX-книгу с «единое» в названии; отдельные книги групп и преподавателей тоже поддерживаются. В папке Drive можно хранить PDF в подпапках «Календарные графики», «Учебные планы» и «Программы ГИА»; бот читает их с правом только на чтение. Для Drive включи Google Drive API в проекте сервисного аккаунта и поделись только этой папкой с его email. Локальные XLSX остаются резервным источником, если Drive не настроен. Файлы расписания не добавляй в публичный репозиторий. Токен задавай только в секретных Variables хостинга.

Для КузТАГиС бот использует открытую папку `https://disk.yandex.ru/d/bbxOH6odZrMXrQ` и читает размещённые там XLSX и DOCX-файлы. Данные обновляются раз в 15 минут и отдельно кэшируются от КузПК.

Для ПГТ им. В. П. Романова бот читает недельные страницы групп, преподавателей и аудиторий с `http://raspisanie.pgt.su/cg.htm`. Списки и страницы расписания кэшируются на 5 минут; расписание звонков на сайте не подключено.

Для ЯМК бот загружает группы ОТП прямо с сайта. Для ОСГП, ОЕНП и ОСЭП сайт публикует общий PDF: бот передаёт его в ConvertAPI для преобразования в XLSX, извлекает из таблицы группы и показывает расписание в Telegram-сообщении. Добавь `CONVERTAPI_TOKEN` в Railway Variables. ConvertAPI объявляет 250 бесплатных преобразований для новых аккаунтов; после бесплатного лимита сервис может потребовать оплату, поэтому установи лимит использования в кабинете ConvertAPI. Содержимое PDF передаётся внешнему сервису конвертации; токен хранится только в Variables и не должен попадать в GitHub.

## Google Таблица
Создай Google Spreadsheet с листами и заголовками:

### Группы
`group`

### Расписание
`date | group | lesson_no | subject | teacher | room | start | end`

Дата: `YYYY-MM-DD`, например `2026-11-09`. При подключённой Google Таблице она имеет приоритет над локальным XLSX.

### Преподаватели
`teacher | subject | groups | room | contact`

### Аудитории
`room | building | floor | comment`

### Звонки
`day_type | lesson | start | end`

Поделись таблицей с email сервисного аккаунта Google с правами редактора. В `.env` укажи `GOOGLE_SHEET_ID` и JSON сервисного аккаунта в `GOOGLE_SERVICE_ACCOUNT_JSON` одной строкой.

## Moodle
В меню «Курсы» бот читает открытый каталог выбранной группы и специальности на портале дистанционного обучения ГАПОУ КузПК. Личные логин и пароль Moodle в боте не используются. Если курс требует авторизации, пользователь открывает его и входит в Moodle самостоятельно.

## Настройка прав
Главный администратор задаётся через `ADMIN_ID`. Его роль определяется автоматически.
Назначение старост и преподавателей на первом этапе можно выполнить напрямую в SQLite через `set_role()` либо добавить команду управления в следующем обновлении. Не выдавай права по имени пользователя — используй Telegram ID.

## Безопасность
Не публикуй `.env`, токен Telegram или ключ Google Service Account. Если токен случайно попал в публичный чат, перевыпусти его в BotFather.
